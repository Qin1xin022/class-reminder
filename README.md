# 课表待办

一个给自己和同学用的小 App：**课程表 + 待办 + 笔记 + 比赛/考试/通知管理 + 上课提醒**。
纯本地存储，不联网、不上传任何数据。

## 📥 下载安装（安卓）

**最新版固定链接**（永远指向最新版，收藏这一个就够了）：

https://github.com/Qin1xin022/class-reminder/releases/latest/download/kebiao-latest.apk

也可以打开 [Releases](../../releases/latest) 页面，下载 `kebiao-latest.apk`。

安装步骤：下载 → 点开 → 提示「未知来源 / 此类文件可能有害」时允许一次 → 安装完成。

## 🔄 更新

下载同一个链接里的新包，点开覆盖安装即可，**课表、待办、笔记都不会丢**。
（覆盖安装的前提是签名一致，本项目固定使用同一个签名证书。）

## ✨ 功能

- **课程表**：一屏看完一整周，左右滑动换周；按广工 12 节作息自动对齐时段；上完的课自动灰显
- **上课提醒**：提前多档提醒，文案带「还有多少分钟上课」
- **待办**：分事件/作业，可单独设提醒时间
- **记录**：类原子笔记的富文本编辑（加粗、斜体、下划线、高亮、字号、字体颜色、对齐、列表、待办清单、插图）
- **比赛 / 考试 / 通知**：按重要性自动排多档提前提醒；通知里的时间、地点、人名自动提取
- **桌面小组件**：今日课程一览
- **换手机**：设置页可导出/导入备份文件，开学周次一起迁移，周次不会错
